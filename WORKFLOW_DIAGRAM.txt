================================================================================
  COMPONENT RESPONSIBILITIES
================================================================================

  Component                 Role                     Automation
  ─────────────────────────────────────────────────────────────────
  STK Push API              Initiates payment        Sends request to customer
  IPN Notification API      Confirms payment         Triggers Supabase insert
  Supabase Trigger 1        Payment → Invoice        Keeps balances accurate
  Supabase Trigger 2        Invoice → Inventory      Manages stock automatically
  Supabase Trigger 3        Inventory → Alert        Prevents stock-outs

================================================================================
  CONFIGURATION
================================================================================

  Environment Variables (KCB):
  • KCB_BUNI_CLIENT_ID
  • KCB_BUNI_CLIENT_SECRET
  • KCB_BUNI_BASE_URL
  • KCB_BUNI_TOKEN_URL
  • KCB_BUNI_CALLBACK_URL = /functions/v1/kcb-ipn-notification

  Settings Table:
  • inventory_alert_threshold = 10 (low stock threshold)
  • inventory_alert_webhook_url = https://your-domain.com/alerts
